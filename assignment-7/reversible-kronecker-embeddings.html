§1   The problem

A lookup table is a strange thing to spend a billion parameters on

Every transformer routes its input through a table \(\mathbf E\in\mathbb R^{|V|\times d_{\text{model}}}\). At \(|V| = 131{,}072\) and \(d_{\text{model}} = 4096\) that is 537 M parameters doing something conceptually mundane: memorising an arbitrary vector for each token ID. Tie nothing, and the output head costs the same again.

Kronecker Embeddings replace the table with a deterministic byte-level encoder plus one learned projection. For a token with bytes \(b=(b_1,\dots,b_L)\),

\[\kappa(b) \;=\; \frac{1}{\sqrt L}\sum_{p=1}^{L}\mathbf c_{b_p}\otimes\mathbf p_p \;\in\;\mathbb R^{D},\qquad D = 256\cdot P,\]

with \(\mathbf c_{b_p}\) one-hot over byte values, \(\mathbf p_p\) one-hot over byte positions, and \(\mathbf e = \kappa(b)\,\mathbf W_{\text{proj}}\). Trainable input parameters drop from 537 M to 33.6 M.

What the method does not give you is the bytes back. \(\mathbf W_{\text{proj}}\) is a dense, freely trained \(8192\times 4096\) matrix; nothing constrains it to be invertible and nothing in the loss preserves its conditioning. That closes off weight tying, byte-level generation, and any form of inspection. This note puts it back.

§2   Locating the loss

The codec is already a bijection. The projection is not.

It pays to be precise about which stage destroys information, because the answer determines how much of the design has to change.

Under the index map \(\iota(v,p) = v\cdot P + p\), the term \(\mathbf c_v\otimes\mathbf p_p\) is exactly the basis vector \(\mathbf e_{\iota(v,p)}\). Group the \(D\) coordinates into position slots \(\Sigma_p = \{\iota(v,p) : v\in\mathcal B\}\). Slot \(p\) receives a contribution from byte position \(p\) and from nothing else.

Lemma 1  ·  the codec is invertible

\(\kappa\) is injective on byte strings of length \(\le P\), \(\|\kappa(b)\|_2 = 1\) exactly, and

\[L=\#\{p:\kappa(b)|_{\Sigma_p}\neq 0\},\qquad b_p=\arg\max_{v\in\mathcal B}\ \kappa(b)[\iota(v,p)].\]
Proof

The pairs \((b_p,p)\) are pairwise distinct because their second coordinates are, so the \(L\) basis vectors are distinct and orthogonal and \(\|\kappa(b)\|^2 = \tfrac1L\cdot L = 1\). Restricted to slot \(p\), \(\kappa(b)|_{\Sigma_p} = \tfrac{1}{\sqrt L}\mathbf e_{b_p}\) for \(p\le L\) and \(\mathbf 0\) otherwise, so the nonzero slots give \(L\) and the argmax within a slot gives \(b_p\). ∎

So reverse determinism is lost in exactly one place: the map \(\mathbb R^{8192}\to\mathbb R^{4096}\). We do not need a new byte encoding. We need one matrix to be structured.

Aside: the per-token z-normalisation in the published pipeline looks like it destroys two degrees of freedom, but on the codec image the mean and variance are functions of \(L\) alone (\(m = \sqrt L/D\), \(\sigma^2 = (1-L/D)/D\)), and an increasing affine map preserves both the argmax and the zero/nonzero slot pattern. It is invertible too.

§3   A tempting dead end

Generic injectivity is true, and useless

Proposition 2  ·  negative result

For Lebesgue-almost every \(\mathbf W\in\mathbb R^{D\times d}\), the map \(b\mapsto\kappa(b)\mathbf W\) is injective on the (finite) set of admissible byte strings.

Proof

Let \(\mathcal D\) be the finite set of nonzero differences \(\kappa(b)-\kappa(b')\). Injectivity fails iff some \(u\in\mathcal D\) has \(u\mathbf W = 0\); for fixed \(u\ne0\) that is a subspace of dimension \((D-1)d < Dd\), hence null, and a finite union of null sets is null. ∎

It would be a mistake to read this as “the existing method is basically reversible.” It fails on three counts, and each one matters more than the theorem:

  • No closed form. Recovery becomes sparse reconstruction — OMP or \(\ell_1\) minimisation, iterative and only conditionally correct.
  • No margin. Injectivity in exact arithmetic says nothing about tolerance to perturbation, which is the only version that survives bf16.
  • Not preserved by training. Nothing in the loss keeps \(\mathbf W\) away from the null set. That the original method needs a self-entropy regulariser against subspace collapse is evidence the drift is real.

We want a structural guarantee that is an invariant of training, not a measure-theoretic one.

§4   Construction

Orthogonal position slots, an equal-norm codebook, two invertible mixers

The whole design space is one idea: the per-position contributions must land in mutually orthogonal subspaces, and each per-position map must be injective with equal norms. Everything below is that idea plus two invertible maps that restore expressivity without costing anything.

\[\boxed{\;\mathbf e(b)\;=\;\operatorname{flat}\!\big(T\,Z(b)\big)\,Q,\qquad Z(b)_{p,:}=\tfrac{1}{\sqrt L}\,g_{b_p}\;}\]
ComponentShapeConstraintRole
\(G\) codebook256 × srows unit-norm, pairwise distinctbyte identity
\(T\) position mixerP × P\(F^{*}\!\operatorname{diag}(w)F\), \(w>0\)position kernel
\(Q\) output mixerd × dorthogonal (Householder product)cross-slot entangling

with \(d = P\cdot s\). Decoding runs the same path backwards: apply \(Q^{\top}\), apply \(T^{-1}\), read \(L\) off the slot norms, then take a 256-way argmax per slot.

Why a 256-way codebook rather than a bit code

A cheaper instantiation exists: give each of the 8 bits of each byte its own orthonormal direction and read the signs. It needs only \(d\ge 8P\) and has zero coherence. I rejected it. A case flip is a single bit, so run and RUN would land at cosine 0.75 — and case-sensitivity is one of the properties that motivates byte-level embedding in the first place. Byte values are categorical, not ordinal: 0x7F and 0x80 are adjacent integers and unrelated characters. The codebook keeps them orthogonal-ish by construction.

§5   Proofs

Row-normalisation is the whole guarantee

Theorem 3  ·  exact reverse determinism

If every row of \(G\) has norm \(r\) and no two rows are equal, \(T\) is invertible and \(Q\) is orthogonal, then \(\mathcal R(\mathbf e(b)) = b\) for every admissible \(b\). Distinctness is also necessary.

Proof

\(QQ^{\top}=I\) returns \(TZ(b)\) exactly and \(T^{-1}\) returns \(Z(b)\) exactly. Equal norms give \(\|Z_{p,:}\| = r/\sqrt L>0\) for \(p\le L\) and \(0\) beyond, so \(\hat L = L\). For the bytes, \(\langle Z_{p,:},g_v\rangle = \tfrac{1}{\sqrt L}\langle g_{b_p},g_v\rangle\le \tfrac{r^2}{\sqrt L}\) by Cauchy–Schwarz, with equality iff \(g_v=\lambda g_{b_p}\), \(\lambda\ge0\); equal norms force \(\lambda=1\) and distinctness forces \(v=b_p\). The argmax is unique and correct.

Necessity: if \(g_u=g_v\) with \(u\ne v\), any two strings differing only at one position by \(u\) vs \(v\) have identical \(Z\), hence identical \(\mathbf e\). ∎

Note what the proof never invokes: no RIP constant, no incoherence assumption, no sparsity threshold, no probability. Unit rows and distinct rows suffice — and both are enforceable by projection after every optimiser step.

Theorem 4  ·  minimal width

A codebook satisfying both constraints exists iff \(s\ge2\). Exact reversibility is therefore available whenever \(d_{\text{model}}\ge 2P\) — 64 dimensions at \(P=32\) — independently of \(|V|\) and \(D\).

Proof

For \(s\ge2\) the sphere \(rS^{s-1}\) is infinite; take any 256 distinct points. For \(s=1\), \(rS^{0}=\{-r,+r\}\) has two elements, so the two constraints are incompatible. ∎

So \(s\) does not decide whether inversion works. It decides how robustly.

Theorem 5  ·  decoding margin

Write \(\mu=\max_{u\ne v}\langle g_u,g_v\rangle/r^2\) for the codebook coherence. If \(\hat{\mathbf e}=\mathbf e(b)+\eta\) with

\[\|\eta\|_2 \;<\; \frac{r\,(1-\mu)}{2\sqrt{L}\,\|T^{-1}\|_2},\]

then decoding is still exact.

Proof

After the two undo steps, \(\hat Z = Z(b)+E\) with \(\|E\|_F\le\|T^{-1}\|_2\|\eta\|_2=\varepsilon\). Length recovery survives because \(\varepsilon< r/(2\sqrt L)\). For bytes, fix \(p\le L\) and \(v\ne b_p\):

\[\langle\hat Z_{p,:},g_{b_p}-g_v\rangle \;\ge\; \frac{r^{2}(1-\mu)}{\sqrt L} \;-\; 2r\varepsilon_p,\]

using \(\|g_{b_p}-g_v\|\le 2r\). This is strictly positive under the hypothesis, so \(b_p\) is the strict argmax for every competitor. ∎

Theorem 6  ·  the margin ceiling (Welch)

\(\mu\ \ge\ \sqrt{\dfrac{256-s}{255\,s}}\), with equality iff the rows form an equiangular tight frame.

§6   The price of compression

You cannot compress and keep the geometry exactly

Theorem 7  ·  distortion floor

Preserving the original codec's inner products exactly requires 256 mutually orthogonal \(g_v\), i.e. \(s\ge 256\), i.e. \(d\ge 256P = D\) — the uncompressed case. Any compression incurs distortion, and the distortion is exactly \(\mu\), bounded below by Welch.

This is worth stating plainly because it converts a vague worry into a number. Compressing 8192 dimensions into 4096 costs 6.3% leakage between byte identities in the best case, and 9.3% with the codebook I actually optimised. An ETF codebook is the minimum-distortion reversible compression; everything else is a choice of where to sit on that curve.

The general inner-product formula follows from orthogonality of \(Q\):

\[\big\langle\mathbf e(b),\mathbf e(b')\big\rangle =\frac{1}{\sqrt{LL'}}\sum_{p,q} R_{pq}\,\big\langle g_{b_p},g_{b'_q}\big\rangle,\qquad R = T^{\top}T.\]

§7   The position mixer

One vector \(w\) is both the invertibility condition and the geometry knob

Take \(T\) circulant, \(T = F^{*}\operatorname{diag}(w)F\). Then \(R = T^{\top}T\) is circulant too, so \(R_{pq} = \rho(p-q)\) with

\[\rho(\delta) \;=\; \frac1P\sum_{k=0}^{P-1} w_k^{2}\,\omega^{k\delta} \qquad\text{— that is, }\ \rho=\mathcal F^{-1}(w^{2}).\]

Position similarity now depends on the offset between bytes rather than on their absolute positions. The original codec is the flat case \(w\equiv1\Rightarrow\rho=\delta_0\).

Corollary 8  ·  shift response

For \(b\) with distinct bytes and \(b'\) its shift by \(\delta\): \(\cos(\mathbf e(b),\mathbf e(b')) = \rho(\delta)/\rho(0)\).

The flat case therefore makes run and ␣run exactly orthogonal — and space-prefixed duplicates are the single most saturated pattern in a BPE vocabulary. It does the same to the shared -tion in nation (positions 3–5) and creation (positions 5–7), which is the paper's own stated limitation. Both are repaired by a non-flat \(w\), at no cost to invertibility, because the only thing invertibility asks of \(w\) is positivity.

The cost is stated exactly by Theorem 5: the margin shrinks by \(\|T^{-1}\|_2\). Normalise \(\max_k w_k = 1\) and the condition number \(\chi = 1/\min_k w_k\) is simultaneously the numerical conditioning and the margin-shrink factor. One knob, both roles, no hidden tradeoff. I use \(\chi = 8\).

Exactness in bf16 is the result that matters. That is the precision at which a generic trained projection would be hopeless, and it is the precision models are actually trained in.

Because slot \(p\) occupies its own subspace, the final hidden state decodes into \(P\) independent 256-way categoricals whose logits reuse the same \(G\). Weight tying — architecturally impossible in the original method, since \(D\ne d_{\text{model}}\) — comes back, and with it the output head's 537 M parameters go to zero. That is where the headline reduction comes from; the input side alone is 33.6 M → 0.295 M.

§9   Training

Every guarantee is an invariant, not a hope

The feasible set is a product manifold, \((rS^{s-1})^{256}\times\mathbb R_{>0}^{P}\times O(d)\), and each factor has a cheap exact parameterisation:

  • \(G\) — renormalise rows after every optimiser step. Keeps Theorem 3 true by construction.
  • \(w\) — \(w_k = w_{\min} + \operatorname{softplus}(\theta_k)\). Positivity and a hard conditioning floor, both free; the kernel \(\rho\) stays learnable inside them.
  • \(Q\) — a product of \(m\) Householder reflections. Exactly orthogonal at every step, \(O(md)\) to apply.

Optionally add \(\lambda\|\text{offdiag}(GG^{\top})\|_F^2\) to push \(\mu\) toward the Welch bound and widen the margin. Nothing here needs a verification pass after training, which is the point — a property you have to re-check is a property that will eventually be violated.

§10   Limits

What this does not settle

  1. No evidence it trains as well. Every number in this note is a property of a linear map. The original method's 2.5% validation-loss win came from a dense, unconstrained projection; I have imposed block-orthogonality and hedged with \(Q\). Whether the hedge suffices is empirical and no proof reaches it. This is the load-bearing uncertainty.
  2. Reversibility holds at the embedding, not at depth. \(\mathcal R\) inverts \(\mathbf e\), not a layer-12 hidden state. Information about \(b\) is non-increasing through the transformer body, and should be.
  3. Truncation collisions are inherited. Two tokens sharing their first \(P\) bytes get identical embeddings. Zero collisions on random strings, but real vocabularies contain long whitespace runs and Indic word-pieces; this needs a check against an actual tokenizer, and a length or overflow slot if it bites.
  4. A tied factorised output head does not follow from reversibility. Theorem 5 bounds noise tolerance; it does not repair the false independence assumption \(P(b\mid\text{ctx})=\prod_p P(b_p\mid\text{ctx})\). After q, u is near-certain, and independent softmaxes cannot say so. Vocabulary reranking or a coupling head is still required.

§11   Next

The one experiment that decides it

Rerun the original paper's three-seed 124 M GPT-2 protocol with \(T=I\) and \(Q=I\) — block-orthogonality alone, one variable changed. If the 2.5% advantage survives that constraint, everything else in this note is free: \(T\) and \(Q\) are invertible additions that cannot remove information, and the tied output head follows from Theorem 3. If it does not survive, the construction is a well-proved answer to a question nobody should ask, and the interesting work is finding out how much of the block constraint can be relaxed while keeping a closed-form inverse.

Ordered after that: verify bit-exactness against a real tokenizer vocabulary; measure the empirical margin distribution rather than the worst case; sweep \(\chi\) against validation loss, since it is entirely possible the transformer prefers hard position boundaries; and only then attempt the tied head, with vocabulary reranking rather than free byte generation.
